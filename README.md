# Promotion Cannibalization & TrueLift

> *“Not every sale is a new sale.”*

A data-driven framework and interactive presentation exploring CPG promotion effectiveness — distinguishing genuine incremental demand from portfolio cannibalization and brand-switching.

---

## 📁 Repository Structure

- **`documents/`**  
  Static problem statement documentation, business relevance, and impact framing.
  - Open `documents/index.html` in any browser.

- **`solution-approach/`**  
  Interactive React + Vite presentation website (**TrueLift**) featuring:
  - Visual storytelling of the cannibalization illusion
  - Counterfactual decomposition of promotion uplift
  - Live Promotion Simulator & Portfolio Risk Graph
  - Real-world CPG case studies & solution architecture

---

## 🚀 Quickstart

To run the interactive solution presentation locally:

```bash
cd solution-approach
npm install
npm run dev
```

Visit `http://localhost:5173/` in your browser.
